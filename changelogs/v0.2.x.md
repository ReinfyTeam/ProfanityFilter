# v0.2.0-beta (Command & UI refresh, beta) - 2026-10-09
- Rebuilt `/pf` on Commando with explicit subcommands (help, ui/gui, list, add, remove, toggle, reload) and permission wiring.
- Swapped the management UI to pmforms; adds in-game enable/disable and reload controls and safer add/remove flows.
- Added Vietnamese translation (`lang: vie`) and refreshed plugin icon/assets.
- Updated the bundled profanity list to the latest Minecraft set, kept it immutable on startup, and de-duplicated custom entries with a sane fallback seed.
- Faster detection via cached regex compilation and trimmed hot-path allocations.
- Hardened config/punishment handling: robust ban-duration parsing, replacement-character validation, max-violation fallback, punish-type normalization, and safer resource bootstrap; update notices now log at debug level.
- Added a formatting-code workaround for Minecraft's client profanity filter in `/pf ui` word labels and management forms (#197), preserving Unicode graphemes and original stored words.
- Updated checkout and artifact actions, fixed pull-request builds to avoid publishing the Poggit branch, and added regression checks for source and packaged UI forms.
- Requires PocketMine-MP API 5.36.0 or later within the 5.x series.
